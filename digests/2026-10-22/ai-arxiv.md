## Signals
Self-improving agent architectures are converging on a pattern: decouple evaluation from execution (VeriEvolve, Agent S4, SSR), synthesize executable verifiers or interfaces from experience, and use population-based or speculative search to evolve them. Memory is becoming a first-class security surface — PerMIT's machine-checked integrity and BackUpper's automatic backup point toward architectures where state changes are auditable and reversible by default. Diffusion language models are emerging as viable agent backbones for latency-critical pipelines (DiffResearch), while model-specific RL systems (FlashNext-RL) demonstrate that kernel-level co-design unlocks order-of-magnitude throughput gains. Evaluation is shifting from aggregate scores to causal attribution (BRA), mechanistic probes (failure attribution grafting), and controlled confounds (RTLRepairBench). Skill distillation via natural language (D-Skill) is proving competitive with weight-based distillation at dramatically lower inference cost, suggesting a path toward portable, interpretable capability transfer. Test-time compute allocation (ARR, StreamStop, BRA) is maturing into a principled discipline with training-free adaptive methods matching or exceeding learned controllers.

## Coding agents & assistants

### Oh My Pi

- **Release:** [v19.1.0](https://github.com/can1357/oh-my-pi/releases/tag/v19.1.0) is a breaking release: the omp extension now uses a pinned Chrome extension ID and connects to the browser relay through its native host, requiring a reinstall via Chrome's "Load unpacked" flow with the relay `--port` and `--token` options removed. It also removes the built-in `google-gemini-cli` OAuth provider, with Google Antigravity and Antigravity CLI still available.

### jcode

- **Release:** [v1.0.3](https://github.com/1jehuang/jcode/releases/tag/v1.0.3) fixes a bug where reading a 13th screenshot dropped earlier images and invalidated the prompt cache, now retaining tool images up to 48 MiB. It adds Antigravity Google login with Gemini 4 (Neon) as the default model.

### DeepSeek Harness

- **Prerelease:** [dsh-v0.2.3-alpha.1](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.3-alpha.1) is a prerelease that adds a code review page for GitHub PRs with GitLab review and merge support, and lets the plugin marketplace install plugins from Git repositories. It also adds optional connectors for services like Linear, Notion, and Feishu.

## Signals
The submissions reveal a convergence on persistent, stateful agent systems as the central abstraction: claw-style agents with long-term memory and skill files (AutoRedClaw, One Skill Takes Over, Dependency-Tethered Memory), full-duplex speech agents with transactional memory (DuplexLedger), and autonomous research agents spanning sessions (Epi). Evaluation is shifting from static benchmarks to evolving, self-tuning suites (TURTLE, EGI-BENCH, VibeTraining-Bench) that unify heterogeneous capabilities under fine-grained metric routing. Security and alignment concerns now target structural properties—authorization composition failures (Local Allow Global Deny), silent tool errors (RITE, CUA-Recovery), and runtime safety gaps between refusal and action (Refuses When Asked)—rather than only final-output harms. Skill/skill-file management emerges as a first-class engineering problem: conflicts cause systematic takeover, but merged files with worked examples resolve it; unsupervised tool evolution (TEAL, EvoSkill v2) and skill-level RSI (Skill-RSI) show reusable capabilities can be compiled offline and deployed cheaply. Multimodal agents increasingly rely on persistent, addressable memory and capability layers (OpenVLHarness, SpatialScout, WildAWM) rather than raw model scaling. Formal methods integrate tightly with agent workflows (Maestro, ABACUS, SPLASH), using coordination, program-guided reasoning, and contrastive audit pressure to overcome single-model limitations.

[Claude Code v2.1.321](https://github.com/anthropics/claude-code/releases/tag/v2.1.321) made Claude Fable 5.2 the default Fable model, and several coding agents changed defaults or shipped breaking changes this week. Azure Databricks published retirements running from [Gemini 3.6 Flash](https://learn.microsoft.com/azure/databricks/release-notes/product/2026/november#gemini-36-flash-will-be-retired-on-november-19-2026) on 2026-11-19 to [GLM 5.2](https://learn.microsoft.com/azure/databricks/release-notes/product/2026/november#zhipu-ai-glm-52-is-scheduled-for-retirement) on 2027-02-04, while the Commission adopted an [implementing regulation on AI regulatory sandboxes](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:32026R2487).

## Claude Fable 5.2 in Claude Code

Release v2.1.321 lists Fable 5.2 at $8/$40 per Mtok, with 1M context and $0.20/Mtok for cache reads. [Pi v1.5.1](https://github.com/earendil-works/pi/releases/tag/v1.5.1) gives the same prices and says that requests its safety classifiers refuse before any output are answered by Claude Opus 5 through server-side fallback and billed at Opus 5's price. [Claude Code v2.1.322](https://github.com/anthropics/claude-code/releases/tag/v2.1.322) added fast mode on Vertex in the global, us and eu regions, falling back to standard speed if Vertex refuses it.

Two more Claude Code releases arrived. [v2.1.323](https://github.com/anthropics/claude-code/releases/tag/v2.1.323) added Code Mode, an experimental opt-in in which Claude writes JavaScript to call its tools, and [v2.1.325](https://github.com/anthropics/claude-code/releases/tag/v2.1.325) fixed a security issue in how zstd-compressed responses are decoded.

Two issues report problems. An [issue on DISABLE_TELEMETRY](https://github.com/anthropics/claude-code/issues/108726) says that with `DISABLE_TELEMETRY` set to 1, the `/model` picker shows Fable 5.1 while `claude --model claude-fable-5-2` works. A [separate report](https://github.com/anthropics/claude-code/issues/109446) says 2.1.323 removed the `subagentStatusLine` setting with no replacement, leaving per-agent context, cost, model and effort invisible.

*The picker report describes one configuration, but it suggests a new default can reach some setups late. The subagent report shows that a display setting can disappear between two releases with no migration path.*

## Coding-agent defaults, fixes and usage

Pi's notes say the anthropic provider now defaults to Claude Opus 5.5 instead of Claude Opus 4.8, and that message threads are on by default for the anthropic provider on api.anthropic.com. [OpenCode v2.2.7](https://github.com/anomalyco/opencode/releases/tag/v2.2.7) removed `ImageResponse.image` from `@opencode/ai`, and the replacement is `response.images[0]`. [OpenCode v2.3.0](https://github.com/anomalyco/opencode/releases/tag/v2.3.0) now always runs subagents in the background and defaults transcript verbosity to `low`. [Codex 0.167.2](https://github.com/openai/codex/releases/tag/rust-v0.167.2) sends tool updates incrementally by default on Google Cloud Vertex AI, with an opt-out setting in `config.toml`.

[Hermes Agent v0.23.1](https://github.com/nousresearch/hermes-agent/releases/tag/v0.23.1) raised the plugin catalog size cap from 2 MiB to 16 MiB. Its notes say a catalog site deploy on 2026-11-09 pushed the published file past the old cap, so installs silently fell back to the catalog they shipped with. A [Hermes Agent issue](https://github.com/NousResearch/hermes-agent/issues/152674) reports that desktop chat messages were admitted under uid:10000 rather than the logged-in user's id, reproduced by its reporter on two accounts.

[Kilo Code](https://kilocode.ai/) is week #5 among OpenRouter apps at 7.03T tokens/week (+46% vs previous week). [omp](https://omp.sh/) is at 2.13T tokens/week on OpenRouter (-36% vs previous week), while its npm downloads are at 295,519 downloads/week (+34% vs previous week).

*The Trends figures cover one week, so they show where usage moved rather than a settled order. A team running several of these agents faces a separate set of defaults for each.*

## Data platform changes and a PostgreSQL CVE

Starting 2026-11-19, calls to Gemini 3.6 Flash will be redirected to Gemini 3.8 Flash at the same price. The [Genie One MCP Beta endpoint](https://learn.microsoft.com/azure/databricks/release-notes/whats-coming#upcoming-end-of-life-for-the-genie-one-mcp-beta-endpoint) reaches end of life on 2026-11-30, and requests then fail; the migration target is the `system.ai.genie_one_mcp` MCP in Unity Gateway. [External access to Unity Catalog managed Delta tables](https://learn.microsoft.com/azure/databricks/release-notes/whats-coming#external-access-to-unity-catalog-managed-delta-tables-will-soon-be-available-by-default-for-workspaces-with-the-compliance-security-profile-enabled) will be available by default on or after 2026-12-10 for eligible workspaces with the compliance security profile enabled. [Smart Routing](https://learn.microsoft.com/azure/databricks/release-notes/unity-gateway#smart-routing-is-faster-and-lower-cost-and-now-routes-subagents-only-beta) now routes only subagents, and it is paused for Codex.

[Databricks CLI v1.25.0](https://github.com/databricks/cli/releases/tag/v1.25.0) removed `CRITICAL` as a `compute.priority_class` value, which the AI Runtime API no longer accepts. [Terraform provider v1.143.0](https://github.com/databricks/terraform-provider-databricks/releases/tag/v1.143.0) now updates `databricks_app` through the asynchronous Apps update API, so changes to `compute_size` and the instance counts now apply. An omitted `compute_size` now resets to `MEDIUM`.

[Snowflake Connector for Python 5.0.0](https://medium.com/snowflake/native-asyncio-comes-to-the-snowflake-python-connector-5941385ac80e) became generally available in October and adds an asyncio API while keeping the synchronous one; a Snowflake post says to check the upgrade guide for behavior changes before switching. [Snowpark Python 1.57.0](https://github.com/snowflakedb/snowpark-python/releases/tag/v1.57.0) no longer takes the `parse_mode`, `row_boundary` and `extract_images` options in `DataFrameReader.documents()`, which is in Private Preview. [Great Expectations 1.25.0](https://github.com/great-expectations/great_expectations/releases/tag/1.25.0) counts rows with a NULL in a compared column as unexpected on SQL backends for four Expectations, matching pandas.

A [Hacker News story](https://www.postgresql.org/support/security/CVE-2026-6460/) links PostgreSQL's security page for CVE-2026-6460, titled "Arbitrary Code Execution in Postgres". Another Hacker News story reports that PostgreSQL released [18.7, 17.12, 16.16, 15.20, 14.25 and 19 RC 2](https://www.postgresql.org/about/news/postgresql-187-1712-1616-1520-1425-and-19-rc-2-released-3442/).

*Three dated items fall between 2026-11-19 and 2026-12-10, the nearest deadlines in this section. The Terraform and Great Expectations changes alter outcomes on upgrade without any change to the code or configuration. No affected versions are named for CVE-2026-6460, so whether the PostgreSQL releases address it is unclear.*

## EU and Dutch AI rules

The implementing regulation sets rules for the establishment, development, implementation, operation and supervision of AI regulatory sandboxes under Regulation (EU) 2024/1689. The Commission's [guidelines on transparency obligations under Article 50](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:52026XC06005) appear as a preparatory document. The [AI Act timeline](https://ai-act-service-desk.ec.europa.eu/en/ai-act/timeline/timeline-implementation-eu-ai-act) lists 2026-12-02 for bans on sexual deepfakes and CSAM generators and for the end of the Art. 50(2) transition. On 2026-11-10 the Commission [opened a consultation](https://digital-strategy.ec.europa.eu/news-redirect/964805) on draft revised election guidelines under the Digital Services Act, which address generative AI and manipulation risks.

In the Netherlands, [Digitale Overheid](https://www.digitaleoverheid.nl/nieuws/kabinet-kiest-voor-ai-die-nederland-vooruithelpt/) reports that the cabinet has chosen a vision of AI for a strong economy, good public services and solutions to societal challenges. Three motions in the Tweede Kamer, tied to the 2027 budget of the Ministry of Economic Affairs and Climate, ask for [a legal framework for liability for damage caused by AI models](https://www.tweedekamer.nl/kamerstukken/detail?id=2026Z24563&did=2026D56703), for [authorities to be equipped to supervise the AI Act](https://www.tweedekamer.nl/kamerstukken/detail?id=2026Z24543&did=2026D56682), and for [an investigation into protecting artists and makers against AI](https://www.tweedekamer.nl/kamerstukken/detail?id=2026Z24559&did=2026D56699).

*The 2026-12-02 entry is the one item in this section that sets a deadline under the AI Act. The Dutch motions and the cabinet's vision set direction without a stated date.*

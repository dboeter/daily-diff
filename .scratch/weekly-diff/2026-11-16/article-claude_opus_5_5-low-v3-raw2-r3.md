Anthropic released Claude Fable 5.2, and Claude Code made it [the default Fable model](https://github.com/anthropics/claude-code/releases/tag/v2.1.321). Google released Gemini 4 Carbon and Gemini 4 Hydrogen, and BigQuery added both. Azure Databricks published several retirement and default-change dates, and the EU adopted an AI Act implementing regulation on regulatory sandboxes.

## Claude Fable 5.2 and Claude Code

Claude Code v2.1.321 added Claude Fable 5.2 (`claude-fable-5-2`) as the default Fable model, with 1M context, $8/$40 per Mtok and $0.20/Mtok cache reads. The same release fixed MCP OAuth requests that sent secrets such as refresh tokens to another host when a server redirected them. [Pi v1.5.1](https://github.com/earendil-works/pi/releases/tag/v1.5.1) gives more detail on billing. Requests that Fable 5.2's safety classifiers refuse before any output are answered by Claude Opus 5 through server-side fallback. They are billed at Opus 5's price. Pi also changed its default `anthropic` model to Claude Opus 5.5. A story titled ["Claude Fable 5.2 scores 65 on Artificial Analysis, highest so far"](https://artificialanalysis.ai/models/claude-fable-5-2) drew 335 points.

The rollout brought friction. [An issue reports](https://github.com/anthropics/claude-code/issues/108726) that `DISABLE_TELEMETRY=1` hides Fable 5.2 from the `/model` picker because feature flags are then ignored. Claude Code v2.1.323 removed the `subagentStatusLine` setting. [An issue](https://github.com/anthropics/claude-code/issues/109446) says this left no replacement for per-agent context, cost, model and effort. One Team subscriber [reports](https://github.com/anthropics/claude-code/issues/107390) that a full weekly allowance was used in about 30 hours and 31 minutes. In the weekly tables, [Claude Code](https://claude.ai/code) ranked week #4 on OpenRouter with 10.80T tokens/week (+7.5% vs previous week). [Kilo Code](https://kilocode.ai/) grew to 7.03T tokens/week (+46% vs previous week), while [OpenClaw](https://openclaw.ai/) fell to 2.69T tokens/week (-46% vs previous week).

*For teams that pin settings or build tooling on Claude Code, this week shows how a model launch and a setting removal can change what users see without any config change on their side. The refusal fallback to Opus 5 pricing is worth watching when estimating Fable 5.2 costs.*

## Databricks dates and changed defaults

Several Azure Databricks notes carry dates. The [Genie One MCP Beta endpoint](https://learn.microsoft.com/azure/databricks/release-notes/whats-coming#upcoming-end-of-life-for-the-genie-one-mcp-beta-endpoint) reaches end of life on 2026-11-30, after which requests fail. The note names `system.ai.genie_one_mcp` in Unity Gateway as the migration target. [Gemini 3.6 Flash](https://learn.microsoft.com/azure/databricks/release-notes/product/2026/november#gemini-36-flash-will-be-retired-on-november-19-2026) retires on 2026-11-19, and calls to it will be redirected to Gemini 3.8 Flash at the same price. [Zhipu AI GLM 5.2](https://learn.microsoft.com/azure/databricks/release-notes/product/2026/november#zhipu-ai-glm-52-is-scheduled-for-retirement) is deprecated and will be retired on 2027-02-04, with GLM 5.3 as the recommended replacement.

Defaults are moving too. Starting on or after 2026-12-10, [external access to Unity Catalog managed Delta tables](https://learn.microsoft.com/azure/databricks/release-notes/whats-coming#external-access-to-unity-catalog-managed-delta-tables-will-soon-be-available-by-default-for-workspaces-with-the-compliance-security-profile-enabled) will be available by default for eligible workspaces with the compliance security profile. After Databricks Runtime 15.4 LTS reaches end of support on 2027-08-19, [all Unity Catalog managed tables](https://learn.microsoft.com/azure/databricks/release-notes/whats-coming#all-unity-catalog-managed-tables-will-be-upgraded-to-catalog-commits) will be upgraded to catalog commits.

Two tooling changes alter behaviour. In [Terraform provider v1.143.0](https://github.com/databricks/terraform-provider-databricks/releases/tag/v1.143.0), `databricks_app` uses the asynchronous update API. An omitted `compute_size` now resets to `MEDIUM`, and an omitted `git_source` clears the app's default git source. [Smart Routing](https://learn.microsoft.com/azure/databricks/release-notes/unity-gateway#smart-routing-is-faster-and-lower-cost-and-now-routes-subagents-only-beta) now routes only subagents, and Smart Routing for Codex is paused.

*The 2026-11-19 and 2026-11-30 dates fall within the next two weeks. The Terraform change means configurations that left compute fields out may now resize apps on apply.*

## Gemini 4 models reach the data platforms

Google introduced [Gemini 4 Hydrogen](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-hydrogen/) as "our daily driver for agentic workflows". It made [Gemini 4 Carbon](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-carbon-now-available/) available to developers and enterprises. BigQuery generative AI functions now support [gemini-4-carbon](https://docs.cloud.google.com/bigquery/docs/release-notes#November_10_2026) and [gemini-4-hydrogen](https://docs.cloud.google.com/bigquery/docs/release-notes#November_12_2026), and both notes call the model generally available. According to the [Oh My Pi v18.18.8](https://github.com/can1357/oh-my-pi/releases/tag/v18.18.8) catalog, Gemini 4 Carbon costs $2 input / $0.10 cached / $10 output per 1M tokens through 2026-11-30, then $4 / $0.20 / $20. On Snowflake, [Anthropic Claude 5.5 and OpenAI GPT-6 models](https://docs.snowflake.com/en/release-notes/2026/other/2026-11-06-claude-5-5-openai-gpt-6-ga) became generally available on 2026-11-06.

*If that catalog price is right, Carbon's cost doubles after 2026-11-30, which matters for any BigQuery batch job sized this month. Both warehouses now offer current models from several labs inside SQL.*

## Security fixes in the data and agent stack

PostgreSQL published [CVE-2026-6460](https://www.postgresql.org/support/security/CVE-2026-6460/), titled "Arbitrary Code Execution in Postgres". PostgreSQL also released [18.7, 17.12, 16.16, 15.20 and 14.25](https://www.postgresql.org/about/news/postgresql-187-1712-1616-1520-1425-and-19-rc-2-released-3442/), an update to all supported versions. A separate write-up describes [turning a 22-year-old Postgres type-confusion primitive into RCE](https://mehmetince.net/part-3-6-how-i-ended-up-turning-a-22-year-old-postgresql-type-confusion-primitive-into-rce-cve-2026-6460/).

On the agent side, [Claude Code v2.1.325](https://github.com/anthropics/claude-code/releases/tag/v2.1.325) fixed a security issue in how zstd-compressed responses are decoded. An open Hermes Agent issue [reports](https://github.com/NousResearch/hermes-agent/issues/62336) that terminal environment snapshots write credential-bearing environment variables to disk in plaintext. [OpenShell v0.1.8](https://github.com/NVIDIA/OpenShell/releases/tag/v0.1.8) now resolves static credentials without placement metadata only in the `Authorization` header. Its notes say custom headers such as `x-api-key` need an explicit placement declaration.

*Credential handling shows up across several agent tools this week: OAuth redirects, environment snapshots and header placement. That makes it a useful review point for agents that run with client secrets.*

## EU AI Act implementation

The Commission adopted [Implementing Regulation (EU) 2026/2487](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:32026R2487) of 2026-11-10 on AI regulatory sandboxes under the AI Act. It also published [guidelines on the Article 50 transparency obligations](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:52026XC06005), listed as a preparatory document. The AI Act calendar lists 2026-12-02 for [bans on sexual deepfakes and CSAM generators and the end of the Art. 50(2) transition](https://ai-act-service-desk.ec.europa.eu/en/ai-act/timeline/timeline-implementation-eu-ai-act). In the Netherlands, a [motion by El Boujdaini c.s.](https://www.tweedekamer.nl/kamerstukken/detail?id=2026Z24543&did=2026D56682) concerns equipping authorities to supervise the AI Act.

*The Article 50 guidelines arrive less than three weeks before the Art. 50(2) transition ends. Clients building generative features in the EU are likely to ask how the guidance applies before that date.*

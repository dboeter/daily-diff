Claude Fable 5.2 is now the default Fable model in [Claude Code](https://github.com/anthropics/claude-code/releases/tag/v2.1.321), and several agent tools changed defaults or removed settings in the same week. [Azure Databricks](https://learn.microsoft.com/azure/databricks/release-notes/product/2026/november#gemini-36-flash-will-be-retired-on-november-19-2026) set retirement and endpoint dates, and the [EU AI Act calendar](https://ai-act-service-desk.ec.europa.eu/en/ai-act/timeline/timeline-implementation-eu-ai-act) dates a set of bans and a transition end to 2026-12-02.

## Claude Fable 5.2 in Claude Code

Anthropic's [Claude Fable 5.2 and Mythos 5.2](https://www.anthropic.com/claude-fable-and-mythos-5-2) post says Fable 5.2 "sets a new bar in coding, finance, and the sciences." [Claude Code v2.1.321](https://github.com/anthropics/claude-code/releases/tag/v2.1.321), published 2026-11-09, adds `claude-fable-5-2` as the default Fable model, with 1M context, $8/$40 per Mtok and $0.20/Mtok for cache reads. [Pi v1.5.1](https://github.com/earendil-works/pi/releases/tag/v1.5.1) adds the model at $8/$40 per million input and output tokens. Its changelog says requests refused by Fable 5.2's safety classifiers before any output are answered by Claude Opus 5 through server-side fallback and billed at Opus 5's price.

An [issue](https://github.com/anthropics/claude-code/issues/108726) reports that with `DISABLE_TELEMETRY` set to 1 in `settings.json`, the `/model` picker does not offer Fable 5.2 and still shows Fable 5.1, while `claude --model claude-fable-5-2` works. The reporter links this to feature flags that the variable stops Claude Code from downloading. The issue shows 5 comments, 12 👍 and +17 in the last 24h.

*The reporter's `--model` test suggests the model is reachable even when the picker leaves it out. One report from one setup points to a possible interaction between a telemetry setting and model choice, not a general fault.*

## Default changes and security fixes in coding agents

[OpenCode v2.3.0](https://github.com/anomalyco/opencode/releases/tag/v2.3.0), published 2026-11-13, now always runs subagents in the background, returning their session ID at once and reporting back when they go idle. Its transcript verbosity now defaults to `low`. [Pi v1.5.1](https://github.com/earendil-works/pi/releases/tag/v1.5.1) also changes the default model for the `anthropic` provider to Claude Opus 5.5 from Claude Opus 4.8, and it stops sending an empty `tools` array to OpenAI-compatible models in a session that has used tools, a change its release says fixes 400 errors from vLLM 0.20+.

[Claude Code v2.1.323](https://github.com/anthropics/claude-code/releases/tag/v2.1.323), published 2026-11-12, removed the `subagentStatusLine` setting, and subagent rows now always use the default look. An [issue](https://github.com/anthropics/claude-code/issues/109446) says the setting was the only place in Claude Code to see each subagent's context, spend, model and effort, and asks for it to return. [Claude Code v2.1.321](https://github.com/anthropics/claude-code/releases/tag/v2.1.321) also fixed MCP OAuth requests that sent secrets, such as refresh tokens, to another host when a server redirected them, and a case where a read-only Bash command ran outside the sandbox without a permission prompt.

*Defaults moved in two of these tools, so an upgrade can change behavior for users who never touched a setting. The Claude Code fixes concern permission checks and credential handling, which matter most where an agent runs shell commands or connects to MCP servers.*

## Databricks retirements and behavior changes

[Gemini 3.6 Flash](https://learn.microsoft.com/azure/databricks/release-notes/product/2026/november#gemini-36-flash-will-be-retired-on-november-19-2026) will retire on 2026-11-19. From that date, API calls to it are redirected to Gemini 3.8 Flash at the same price, which the note recommends. [Zhipu AI GLM 5.2](https://learn.microsoft.com/azure/databricks/release-notes/product/2026/november#zhipu-ai-glm-52-is-scheduled-for-retirement) is deprecated and will retire on 2027-02-04, with GLM 5.3 recommended as the replacement. The [Genie One MCP Beta endpoint](https://learn.microsoft.com/azure/databricks/release-notes/whats-coming#upcoming-end-of-life-for-the-genie-one-mcp-beta-endpoint) reaches end of life on 2026-11-30, after which requests fail, and the note says to migrate all workloads to the `system.ai.genie_one_mcp` MCP in Unity Gateway.

[Smart Routing](https://learn.microsoft.com/azure/databricks/release-notes/unity-gateway#smart-routing-is-faster-and-lower-cost-and-now-routes-subagents-only-beta), in Beta, now routes only subagents, not the first prompt. Azure Databricks says it costs up to 70% less in internal benchmarks, and Smart Routing for Codex is paused. [Terraform provider v1.143.0](https://github.com/databricks/terraform-provider-databricks/releases/tag/v1.143.0), published 2026-11-16, moves `databricks_app` updates to the asynchronous Apps update API, so changes to `compute_size`, `compute_min_instances` and `compute_max_instances` now take effect. An omitted `compute_size` now resets to `MEDIUM`.

A [PostgreSQL security page](https://www.postgresql.org/support/security/CVE-2026-6460/) for CVE-2026-6460 is titled "Arbitrary Code Execution in Postgres."

*Of the dated changes here, only the Genie One endpoint is described as failing requests after its date; the Gemini redirect keeps calls running at the same price. The CVE title names code execution but does not show which versions it reaches.*

## EU and Dutch AI rules

[Commission Implementing Regulation (EU) 2026/2487](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:32026R2487), dated 2026-11-10, is listed as adopted and lays down rules for AI regulatory sandboxes under the AI Act. [Guidelines on the transparency obligations for certain AI systems under Article 50](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:52026XC06005), published 2026-11-12, are listed as a preparatory document. The AI Act calendar lists 2026-12-02 for bans on sexual deepfakes and CSAM generators and for the end of the Art. 50(2) transition. A [targeted consultation](https://digital-strategy.ec.europa.eu/news-redirect/964768) on draft revised election guidelines under the Digital Services Act focuses on measures that Very Large Online Platforms and Very Large Online Search Engines should adopt against generative AI and information manipulation risks to electoral processes.

Dutch motions tied to the 2027 budget of the Ministry of Economic Affairs and Climate concern [liability for damage caused by AI models](https://www.tweedekamer.nl/kamerstukken/detail?id=2026Z24563&did=2026D56703), [how authorities can be equipped to supervise the AI Act](https://www.tweedekamer.nl/kamerstukken/detail?id=2026Z24543&did=2026D56682), and [how artists and creators can be better protected against AI](https://www.tweedekamer.nl/kamerstukken/detail?id=2026Z24559&did=2026D56699).

*The Dutch items are motions, while the EU sandbox regulation is listed as adopted and the Article 50 guidelines as preparatory. For clients under the AI Act, the 2026-12-02 entry is the one date here worth watching.*

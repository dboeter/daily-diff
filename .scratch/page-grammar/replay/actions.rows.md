Starting January 31, 2027, the BigQuery Data Transfer Service for Shopify connector will no longer support the following fields (BigQuery) — Starting January 31, 2027, the BigQuery Data Transfer Service for Shopify connector will no longer support the following fields: The legacyMode field from the DeliveryProfile dataset schema The permitSkuSharing field from the FulfillmentService dataset schema For more information, see January 31, 2027.
2. Zhipu AI GLM 5.2 is scheduled for retirement (Azure Databricks) — Zhipu AI GLM 5.2 is deprecated and will be retired on February 4, 2027. GLM 5.3 is the recommended replacement. See Legacy, deprecated, and retired models for migration guidance.
3. All Unity Catalog managed tables will be upgraded to catalog commits (Azure Databricks) — After Databricks Runtime 15.4 LTS reaches end of support on August 19, 2027, Azure Databricks will upgrade all Unity Catalog managed tables to use catalog commits. With catalog commits, Unity Catalog becomes the system of coordination for your tables. This enables multi-statement, multi-table transactions, writes from external engines, and consistent governance across all engines. See Catalog commits.
4. Gemini 3.6 Flash will be retired on November 19, 2026 (Azure Databricks) — Google Gemini 3.6 Flash will be retired on November 19, 2026. Starting on that date, API calls to Gemini 3.6 Flash will be automatically redirected to Gemini 3.8 Flash at the same price. Gemini 3.8 Flash is the recommended replacement. See Legacy, deprecated, and retired models for migration guidance.

1: On January 31, 2027, the BigQuery Data Transfer Service Shopify connector will stop supporting `legacyMode` in the `DeliveryProfile` dataset schema and `permitSkuSharing` in the `FulfillmentService` dataset schema, so any use of those fields must be migrated before then.
2: On Azure Databricks, client workloads using `GLM 5.2` must migrate to `GLM 5.3` by February 4, 2027, when the model is retired.
3: After `Databricks Runtime 15.4 LTS` reaches end of support on August 19, 2027, Azure Databricks will upgrade Unity Catalog managed tables to use `catalog commits`, making Unity Catalog the coordination system and enabling multi-statement, multi-table transactions, writes from external engines, and consistent governance across engines.
4: On November 19, 2026, calls to `Gemini 3.6 Flash` will be automatically redirected to `Gemini 3.8 Flash` at the same price; `Gemini 3.8 Flash` is the recommended replacement.

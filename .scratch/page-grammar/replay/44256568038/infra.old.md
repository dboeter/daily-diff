## OpenShell
- **Release:** [v0.1.9](https://github.com/NVIDIA/OpenShell/releases/tag/v0.1.9) moves the Go SDK to `github.com/ai-openshell/sdk-go` and deprecates `github.com/NVIDIA/OpenShell/sdk/go`, stops wildcard network-policy endpoints from allowing private IP literals without an exact endpoint or `allowed_ips` grant, switches the Helm chart to enable Prometheus metrics with `metrics.enabled` instead of the port value so charts that set `service.metricsPort` to `0` or `false` fail to render, and makes middleware selectors that include a port fail validation. It also makes Postgres migration `010` block writes to the `objects` table while building indexes, makes write-authorization denials report `Create`, `Update`, or `Delete` under `class_uid: 6003` and `status_id: 2` instead of `type_uid: 600399`, records user and operator changes as OCSF API Activity events, includes opt-in HTTP streaming hooks through `openshell.supervisor-middleware.http-hooks`, and exposes `mutation_admission_limit_per_caller` and `mutation_replay_window_seconds`.

## Claude Code
- **Release:** [v2.1.327](https://github.com/anthropics/claude-code/releases/tag/v2.1.327) fixes worktree server shutdown deleting git-ignored files such as `.env`, `--use-anthropic-git-proxy` deleting a directory named by `GIT_CONFIG_GLOBAL`, project-scoped `claude mcp add` and `claude mcp remove` deleting other `.mcp.json` keys, commands you had allowed still running after `Stop`, and `/export` overwriting without asking. It also ships `claude mcp add-json -`, a `/status` report of broken agent, skill, command and output-style files, keybinding errors, an unavailable sandbox, ignored permission settings, and hook matchers that never match, an `attributionProject` billing-group setting, and `/tui classic`.
- **News:** [How the Claude Code team thinks about verification](https://news.ycombinator.com/item?id=50529612) says end-to-end, property and differential tests let coding agents verify work with evidence, and describes what the Claude Code team does to keep its verifiers honest.

## OpenAI Codex
- **Release:** The range from [rust-v0.169.1](https://github.com/openai/codex/releases/tag/rust-v0.169.1)–[rust-v0.170.0](https://github.com/openai/codex/releases/tag/rust-v0.170.0) fixes Windows file replacement, sandbox permission preservation and runtime registration recovery, permission updates and child threads losing sandbox restrictions, MCP OAuth credential races, oversized WebSocket fallback, and duplicate file-search results. It also adds WebRTC negotiation for realtime voice calls in the TUI, automatically refreshed authentication headers for OpenTelemetry HTTP exporters, and experimental support for identically named MCP servers across environments.
- **Hot issue:** #57101: An issue reports that Windows Computer Use leaves the gold/yellow display border and Windows capture-access record open after a screenshot-producing turn completes, with the helper still running about five hours later.

## OpenCode
- **Release:** The range from [v1.19.6](https://github.com/anomalyco/opencode/releases/tag/v1.19.6)–[v2.3.2](https://github.com/anomalyco/opencode/releases/tag/v2.3.2) fixes GPT-6.2 system-prompt caching so Responses routes stop re-billing `instructions` as uncached input, `webfetch` structured output repeating `url` and `format`, and oversized image histories from sending oversized requests. It also changes timed-out shell commands to move to the background instead of being killed, makes `compaction.background` default-on, adds GPT-6.2 with ChatGPT sign-in and plugin updates from Settings, and offers OpenCode 1 users an upgrade to OpenCode 2.0 with sessions, projects and settings kept but OpenCode 1 plugins needing updates.
- **Hot issue:** #37216: An issue reports that `packages/tui` has hardcoded English strings while app, desktop and console packages have i18n support, making the terminal experience inaccessible for non-English speakers, and proposes an i18n key system plus a `locale` option in `opencode.json`.

## Oh My Pi
- **Release:** The range from [v18.22.1](https://github.com/can1357/oh-my-pi/releases/tag/v18.22.1)–[v18.22.2](https://github.com/can1357/oh-my-pi/releases/tag/v18.22.2) makes the JavaScript eval `commit` helper stricter, throwing `TypeError` for unknown or non-object options and reporting an unchanged draft repository instead of suggesting `take()`. The same range fixes provider-error handling so failed tool calls are no longer fed back as refusal explanations, one-shot retries and title generation for custom Zhipu Coding Plan providers to honor Beijing-time quota resets, and OpenAI remote compaction dropping configured headers for header-authenticated gateways; it also adds a native Kiro provider and `omitDemotedReasoning` for Anthropic streams.
- **Hot issue:** #19578: An issue reports that `openai-codex/gpt-6.2-sol` and `gpt-6.2-astra` are absent from the Codex model list after `omp models refresh`, and that direct requests fail model resolution or return `model_not_found`, while native Codex CLI lists and completes a GPT-6.2 Sol request.

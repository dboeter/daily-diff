## Claude Code

- **Release:** [v2.1.326](https://github.com/anthropics/claude-code/releases/tag/v2.1.326) fixes `cp` of a file being refused when only its source is covered by an `Edit` deny rule, a misleading "Dangerous rm operation" warning on some commands, and background sessions losing the shell-exported LLM gateway after a crash. It adds support for turning on Code Mode while agent teams are enabled.
- **Hot issue:** #110480: An issue reports that since around the week of November 9, 2026, premium-seat (Team/Enterprise) usage limits are being exhausted roughly 3–5x faster on non-Fable models (Opus/Sonnet), org-wide, with the same workloads hitting limits after about 20–30% of the usual work; the reporter suggests it may point to a change in how non-Fable usage is metered or counted.
- **News:** [Tokendoctor – the same Claude Code for up to 38% less](https://news.ycombinator.com/item?id=50526584) presents tokendoctor, a locally-run Claude Code plugin that shows where your usage overpays and fixes it with an approved (reversible) diff, with the "up to 38% less" as the poster's claim.

## OpenCode

- **Release:** [v1.19.6](https://github.com/anomalyco/opencode/releases/tag/v1.19.6) fixes oversized requests from image-heavy sessions (once a session's image history passes 25 MiB, the oldest images are replaced with a placeholder) and turns a "request body too large" provider error into a compaction-and-retry instead of a failed turn. The Desktop app now offers an upgrade to OpenCode 2.0 that downloads in the background and installs only when you choose, keeping sessions, projects, and settings, though plugins made for OpenCode 1 need an update.
- **News:** [OpenCode Browse](https://news.ycombinator.com/item?id=50523459) lets OpenCode and other MCP clients drive your real browser—agents can read, click, type, and take screenshots, record tabs, and hand logins and 2FA back to you.

## Oh My Pi

- **Release:** [v18.21.0](https://github.com/can1357/oh-my-pi/releases/tag/v18.21.0)–[v18.22.0](https://github.com/can1357/oh-my-pi/releases/tag/v18.22.0) carry several breaking API changes: disassembler tooling moves into the backend-neutral `dsm` namespace (`xd://eval/dsm`) with `ida.*` settings replaced by `disassembler.*`, `TtyWriter` now requires a drain threshold and callback, terminals with backpressure must implement `onOutputDrain(callback)`, `PlanReviewOverlay` switches to `PlanReviewOverlayChoice` objects, and the `AgentSession` lifecycle replaces `hasPendingAsyncWork()`/`settleAsyncWork()`/`suppressAutoResumeUntilPrompt()` with `isRunActive`, `wakeSources`, and `waitForRunEnd()`. It fixes slow streaming of Gemma tool calls with large arguments and the misidentification of `grok-composer-2.5-fast` as non-reasoning, and adds Ghidra support with automatic setup (Auto mode uses an installed IDA Pro when available, otherwise Ghidra), Google Docs-style comments and editing in Tern plan review, inline image and web-page replies (`tui.renderEmbeds` to disable), Modal as a hosted inference provider, and configurable subagent prewalk via `task.agentPrewalkAuto`.

## jcode

- **Release:** [v1.0.0](https://github.com/1jehuang/jcode/releases/tag/v1.0.0) officially launches jcode Cloud, letting you move a session or swarm to a VM with `/cloud` and bring the conversation and repository back with `/local` after working through a disconnect; it also reworks swarms to plan jobs in phases and parallel lanes that auto-start workers as dependencies finish, and adds typo-tolerant full-conversation search in `/resume` plus live voice input with a streaming draft transcript. According to the release, a profiled release client used 25% less CPU, idle wakeups fell from 2.68 to 1.51 per second, and a 7,000-message session's initial history payload shrank from 14.3 MB to 261 KB.

## Hermes Agent

- **Release:** [v0.23.2](https://github.com/nousresearch/hermes-agent/releases/tag/v0.23.2) is a patch release rolling up roughly 1,989 PRs merged since v0.23.1 into stable builds for the CLI and installers, the Microsoft Store app, Docker, and Hermes Cloud, with full curated notes deferred to v0.24.0. Among the release-candidate fixes, Desktop chats from an August build with a bare `custom` provider can send again after updating and a mid-stream crash on Telegram no longer shows a duplicate "Recovered reply"; the announcement also flags changes kept out of these notes, including durable subagents that survive a gateway restart or crash, `hermes fallback check`, `hermes update --force`, new plugin APIs (`ctx.fork_session`, `ctx.redact_text()`, `ctx.register_idle_task`), and the Gemini Interactions API now used by default for Gemini 3 and later and Gemini 4 Carbon.
- **Hot issue:** #156670: A feature request reports that on multi-monitor Macs `computer_use` can disrupt the person sharing the machine—its foreground fallback brings the app forward and posts system-wide input that collides with the user's mouse and keyboard, with no approval prompt in `--yolo`/no-approval sessions—and proposes making `foreground: ask` the default (surviving `--yolo`) and adding an `avoid_active_display` option.

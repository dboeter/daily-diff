1: Set `spark.databricks.streaming.realTimeMode.realTimeWatermark.enabled` to `false` before starting a new real-time streaming query to keep the previous watermark behavior; otherwise new queries use real-time watermark propagation by default, filtering late events against the live watermark and evicting state sooner, while queries restarted from an existing checkpoint keep their original behavior.
2: Admins can manage one Genie Code budget across the CLI and workspace, and users can apply their free monthly Genie usage in the CLI.
3: Workspaces with the compliance security profile enabled will get IP functions by default, enabling operations and joins on IP addresses and CIDR blocks.
4: Serverless jobs and pipelines can cap Spark executor autoscaling by setting a size on an automated compute object.
5: Governed tag propagation now supports classic compute running Databricks Runtime 19 or above as well as serverless compute, propagating source tags to derived tables and views on either.
6: PostgreSQL change data can be ingested into Azure Databricks through a single integrated CDC pipeline, with no separate ingestion gateway.
7: Budgets scoped to Unity Gateway, including Genie budgets, can set daily per-user thresholds alongside monthly ones, with separate alert, webhook, and block usage actions for each period; daily thresholds reset at 00:00 UTC.
8: External Iceberg engines can query Unity Catalog views over Iceberg-compatible tables through the Iceberg REST catalog.
9: Providers can add Unity Catalog agent skills to OpenSharing shares and Azure Databricks Marketplace listings; Databricks-to-Databricks recipients get read-only access to each shared skill in the catalog created from the share, and provider changes reach recipients asynchronously.
10: Organizations can create, evaluate, and optimize production-ready Cortex AI Functions for unstructured and multimodal data workflows, with automation of prompt engineering, model selection, benchmarking, and optimization.
11: Customers can use the `AIFUNCTIONOPTIMIZATION` experiment type to automatically search prompts and models for improved custom AI Function implementations, evaluating multiple model candidates.
12: Adding `INCLUDE HIERARCHY` to `SHOW GRANTS TO` statements lists grants held by every role in a grantee's role hierarchy, not only grants made directly to that role or user.
13: The author migrated the Apache Ossie demo from Streamlit in Snowflake to Snowflake App Runtime as a Next.js app and found metrics unchanged because definitions lived in a Snowflake semantic view; the same question returned 115,550 without the semantic view and 103,200 with it.
14: The author benchmarked Snowflake Postgres mirroring for two days on the smallest instance that supports mirroring and found new rows appeared in `TABLE$live` after about 26 seconds median and 37 seconds at p90, regardless of whether the refresh interval was 30 seconds or 10 minutes; the table itself lagged by up to one refresh interval.

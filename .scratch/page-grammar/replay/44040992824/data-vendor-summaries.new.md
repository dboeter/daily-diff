1: Set `spark.databricks.streaming.realTimeMode.realTimeWatermark.enabled` to `false` before starting a new streaming query in real-time mode to keep the previous behavior, because starting with this release new real-time queries use real-time watermark propagation by default. Stateful operators advance the watermark within a batch, filtering late events against the live watermark and evicting state sooner, while queries restarted from an existing checkpoint keep their original behavior.
2: Genie Code CLI can be managed like Genie Code in the workspace, with one Genie Code budget shared by admins across both, and users can apply free monthly Genie usage in the CLI.
3: Workspaces with the compliance security profile enabled will get `IP functions` by default for working with IP addresses and CIDR blocks, including joins.
4: Spark executor autoscaling for serverless jobs and pipelines can be limited by setting a size on an automated compute object.
5: Governed tag propagation covers classic compute running `Databricks Runtime 19` or above as well as serverless compute, propagating tags from a source to derived tables and views.
6: Change data from PostgreSQL can be ingested into Azure Databricks through a single integrated CDC pipeline without a separate ingestion gateway.
7: Budgets scoped to Unity Gateway, including Genie budgets, can use daily per-user thresholds, monthly per-user thresholds, or both, with separate alert, webhook, and block usage actions for each period; daily thresholds reset at 00:00 UTC.
8: External Iceberg engines can query Unity Catalog views over Iceberg-compatible tables through the Iceberg REST catalog.
9: Providers can add Unity Catalog agent skills to OpenSharing shares and Azure Databricks Marketplace listings, with Databricks-to-Databricks recipients receiving read-only access in a catalog created from the share and provider changes reaching them asynchronously.
10: Cortex AI Function Studio enables organizations to create, evaluate, and optimize production-ready Cortex AI Functions for unstructured and multimodal data workflows, automating prompt engineering, model selection, benchmarking, and optimization.
11: Cortex AI Function Optimization automatically searches across prompts and models for improved custom AI Function implementations, using the `AIFUNCTIONOPTIMIZATION` experiment type to evaluate multiple model candidates.
12: `SHOW GRANTS TO` statements accept `INCLUDE HIERARCHY` to list grants held by every role in a grantee's role hierarchy, not only grants made directly to that role or user.
13: The author moved the Apache Ossie demo from Streamlit in Snowflake to a Next.js app on Snowflake App Runtime, keeping metric definitions in a semantic view so the interface changed without changing the reported numbers.
14: The author measured Snowflake Postgres mirroring and reported new rows in `TABLE$live` after about 26 seconds at the median and 37 seconds at p90, whether the refresh interval was 30 seconds or 10 minutes.

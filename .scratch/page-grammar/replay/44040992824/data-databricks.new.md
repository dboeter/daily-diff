## Terraform provider for Databricks

- **Release**: [v1.143.0](https://github.com/databricks/terraform-provider-databricks/releases/tag/v1.143.0) moves `databricks_app` updates to the asynchronous Apps update API, so changes to `compute_size`, `compute_min_instances`, and `compute_max_instances` now take effect (the synchronous API ignored them), and because an update replaces updatable fields, omitting them now clears settings — an omitted `compute_size` resets to `MEDIUM`, omitted `compute_min_instances`/`compute_max_instances` disable horizontal scaling, and an omitted `git_source` clears the app's default git source. It fixes a perpetual diff on `databricks_connection` by keeping the configured values of `pem_key_passphrase`, `ssl_keystore_key`, `ssl_key_password`, and `schema_registry_api_secret` and ignoring whitespace-only differences in PEM-encoded options, and adds the `databricks_assume_group_restricted_sharing_group` resource and data sources.

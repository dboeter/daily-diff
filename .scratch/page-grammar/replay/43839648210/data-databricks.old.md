## Terraform provider for Databricks

- **Release**: [v1.143.0](https://github.com/databricks/terraform-provider-databricks/releases/tag/v1.143.0) switches `databricks_app` updates to the asynchronous Apps update API; the synchronous API ignored `compute_size`, `compute_min_instances`, and `compute_max_instances`, so changes to them never took effect, and updates now wait for the app update to reach `SUCCEEDED`. Since an update replaces the app's updatable fields with the configuration, fields omitted from it are cleared, which now covers an omitted `compute_size` resetting to `MEDIUM`, omitted `compute_min_instances` and `compute_max_instances` disabling horizontal scaling, and an omitted `git_source` clearing the app's default git source.
- **Release**: Fix `databricks_connection` keeping the configured values of the `pem_key_passphrase`, `ssl_keystore_key`, `ssl_key_password`, and `schema_registry_api_secret` options, which the API does not return, to avoid a perpetual diff. Fix it ignoring whitespace-only differences in PEM-encoded options such as `userProvidedServerCertificate`, which also caused a perpetual diff.
- **Release**: Add resource and data sources for `databricks_assume_group_restricted_sharing_group`, plus write-only attributes `personal_access_token_wo` and `personal_access_token_wo_version` on `databricks_git_credential` and `options_wo` and `options_wo_version` on `databricks_connection`.
